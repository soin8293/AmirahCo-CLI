# Android and Termux status

The r8 tester installer supports Windows x64. There is no qualified Android installer or accepted Termux/proot setup for this release.

Earlier experimental Termux instructions remain in Git history. They used older source paths, runtime versions and provider examples. They are not a current installation procedure or a guarantee that guided intake, native tools, storage and recovery work on Android.

Use [Windows setup](docs/quick-start-windows.md) for the tester pilot. For source work, read [development](docs/DEVELOPMENT.md) and [Linux/macOS source limits](docs/quick-start-mac-linux.md).

Before claiming Android support, qualify the actual runtime architecture, native dependencies, Linux environment, writable local state, terminal interaction, Stop/reopen and interrupted-save behavior on the intended device. Installing a shell or starting a model request alone does not establish those results.
