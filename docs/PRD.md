# Public release PRD

## User experience

Windows users install and open AmirahCo CLI, configure their own supported provider key, then choose new chat, guided new project or saved work. The logo, globe, info table, scrolling/history and native menus/tabs remain. Guided intake produces context and a reviewable PRD; approval remains separate from Build. Build starts the next eligible work step without another activation message.

## Workflow and autonomy

Reuse native sessions/tools/permissions and the existing Foundry lifecycle. Context-backed reversible decisions within approved scope should not need routine owner questions. Record assumptions and observed failures. Stop, unclear authority, missing credentials, exhausted credit, unresolved effects, material scope changes and final owner acceptance remain genuine holds. One selected agent means one total. Larger teams must use the selected total and no hidden reviewers.

## Release gates

1. BYOK first-run setup and optional hosted-account access stay separate; no owner key or private operational state ships.
2. Current source, build inputs, notices, Windows artifact hashes and capability claims agree. No automatic publication or merge.
3. Manual tester approval, caps, expiry, revocation, replacement and contention pass without granting hidden allowance.
4. Saved intake, sessions, Stop and unfinished work survive install-over and interrupted update. No replay of uncertain external actions.
5. One-agent and selected-team project qualification must close the applicable actual evidence gaps before broad hands-free claims.
6. Partner evaluation reporting is aggregate and content-free; no automatic email sending or billing/fallback changes.
7. License, signing, complete production upgrade and fresh-device receiving dispositions precede public release.

The maintained private project PRD remains the detailed engineering authority. This public view intentionally excludes private partner correspondence, credentials, account records and infrastructure administration details.
