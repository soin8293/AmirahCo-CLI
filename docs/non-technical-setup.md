# Start without building from source

AmirahCo CLI helps you describe a project, review its plan, work with coding agents and check the results in your terminal.

For the Windows tester release:

1. Follow [Install and run on Windows](quick-start-windows.md). Download and run the EXE, then open the Desktop shortcut. You do not need to install developer tools separately.
2. Choose **Add API key**. Connect your own supported provider, or sign in for separately approved tester access.
3. Choose **New chat** for a conversation, or **New project** for guided questions and a reviewable PRD.
4. Follow the [first-project walkthrough](FIRST-PROJECT.md). Review the PRD before choosing Build.

Use the arrow keys and Enter in menus. Your provider supplies the AI model and applies its own usage limits. The optional partner pilot also has manual approval, expiry, quotas and availability limits.

When returning, use **Session history** for a conversation or **Open saved project** for intake and PRD work. A stopped project needs an explicit resume. Reopening it is not permission to start a different project or repeat an uncertain action.

If setup fails, use [troubleshooting](TROUBLESHOOTING.md). Never post a key, login link or private project file in an issue. You can inspect the [built-in skills](WORKFLOWS-AND-SKILLS.md) without installing the original skill repositories yourself.
